## Slide 8 — KOKUDOが実現する3つのこと

```
① 走った距離が、そのまま実在の国道の走破距離になる

② 実地図の上で、自分の挑戦状況が色分けされて見える
   (未走破=グレー / 挑戦中=ネオンブルー / 完走=ゴールド)

③ 完走までの残り距離を、期日から逆算してナビしてくれる

→ 実際の動作をご覧ください(デモ動画 75秒)
```

# 国道ラン（Flutter版プロトタイプ）

Vite+React/TypeScriptで作成していたUIプロトタイプを、Flutter（Dart）に移植したものです。
ホーム／ランニング計測／走破・地図コレクションの3画面と、見た目・配色・インタラクションを
できる限り忠実に再現しています。

## ⚠️ 重要：セットアップ前に必ずお読みください

この移植コードを書いた開発環境には **Flutter/Dart SDKが無く、ネットワーク制限のため
インストールもできませんでした**。そのため `flutter analyze` や `flutter run` のような
実際のコンパイル・静的解析による検証が一切できていません。

コードは1ファイルずつ手作業で見直し、見つかった問題（`num`/`double`の型不一致など、
Dartの `.clamp()` が `num` を返す既知の罠）は修正済みですが、**最終的な動作確認は
お手元の環境で `flutter pub get` → `flutter analyze` → `flutter run` を実行して
必ず行ってください。** コンパイルエラーや細かい不具合が残っている可能性があります。

## セットアップ手順

このzipには `lib/`・`pubspec.yaml`・`assets/` のみが入っており、`flutter create` が
生成するプラットフォーム固有のフォルダ（`android/` `ios/` `web/` など）は含まれていません。
以下の手順でプロジェクトとして初期化してください。

1. このzipを展開し、フォルダごと適当な場所に配置します（例: `kokudo_run_app/`）。
2. ターミナルでそのフォルダに移動し、以下を実行してプラットフォームの雛形を生成します。
   これは既存の `lib/` `pubspec.yaml` `assets/` を壊さず、不足しているフォルダだけを
   追加してくれます。

   ```
   flutter create --org com.example --project-name kokudo_run_app .
   ```

3. 依存パッケージを取得します。

   ```
   flutter pub get
   ```

4. 静的解析でコンパイルエラーが無いか確認します（重要）。

   ```
   flutter analyze
   ```

   もしエラーが出た場合は、内容を教えていただければ修正します。

5. エミュレータ／実機で起動します。

   ```
   flutter run
   ```

## 使っているパッケージ

- `google_fonts` … Noto Sans JPフォントを読み込むために使用しています。初回起動時に
  フォントファイルをネットワーク経由で取得する仕様のため、完全オフライン環境で動かす
  場合はフォントを `assets/fonts/` に同梱して `pubspec.yaml` の `fonts:` セクションで
  指定する形に切り替える必要があります（希望があれば対応します）。

## 元のReact版からの主な変更点・移植方針

- **画面切り替えナビ（画面上部のタブ）はデモ用の開発用UI** です。実プロダクトでは
  ボトムナビ等に置き換わる想定で、そのままにしてあります。
- Web版で使っていた `.phone-frame`（スマホ風の枠・影の装飾）は、実機で動くFlutter
  アプリには不要なため外しました。
- 走破・地図コレクション画面の地図は、Web版ではSVGで描画していましたが、Flutterには
  SVGを直接描く標準機能が無いため `CustomPainter` で同等のブロブ地図・ピンマーカー・
  Googleマップ風の配色/装飾（ズームボタン・縮尺バー等）を描き直しています。
- 路線一覧は、Web版は固定サイズ（390×844のモックアップ枠内で非スクロール）でしたが、
  実機では画面サイズが可変なため `ListView` でスクロール可能にしています。
- キャラクターの走行アニメーションは `character-run.webp`（背景透過・フェザリング済み）
  を優先的に読み込み、失敗した場合は `character-run.gif`、それも失敗した場合は
  簡易アイコン表示にフォールバックします。
- ランニング計測画面の「スタート」ボタン、地図画面のGoogleマップ風の配色・ピン・
  ズームコントロールなど、直近のWeb版での変更はすべてこちらにも反映済みです。

## 構成

```
lib/
  main.dart                  … エントリーポイント
  app.dart                   … MaterialApp / 画面切り替えのルートシェル
  theme/app_colors.dart      … カラー・寸法トークン
  models/route_models.dart   … データモデル
  data/mock_data.dart        … モックデータ・集計関数
  utils/pace_utils.dart      … 逆算計算（完走ナビ）・フォーマット関数
  widgets/                   … 共通ウィジェット（地図・カード・進捗バー等）
  screens/                   … ホーム／ランニング計測／地図の3画面
assets/
  road-bg.webp                … 背景イラスト
  character-run.gif/.webp     … キャラクターアニメーション
```
